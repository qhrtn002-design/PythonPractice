# Python 객체(Object)와 복사(Copy)

---

# 1. 객체(Object)와 참조(Reference)

## 객체란?

파이썬에서 모든 값은 **객체(Object)** 이다.

변수는 값을 직접 저장하는 것이 아니라 **객체를 참조(가리킴)** 한다.

```python
a = [1, 2, 3]
```

위 코드에서

- 리스트 `[1, 2, 3]`라는 객체가 생성되고
- 변수 `a`는 그 객체를 참조한다.

즉,

```
a ─────► [1, 2, 3]
```

---

## 변수 대입(=)의 의미

많은 사람들이

```python
b = a
```

를 복사라고 생각하지만,

실제로는 **같은 객체를 함께 참조**하는 것이다.

```
      ┌──────► [1,2,3]
a ────┤
      └──────► b
```

따라서 한쪽에서 수정하면 다른 쪽도 같이 바뀐다.

---

## is와 ==의 차이 ⭐

이 둘은 반드시 구분해야 한다.

### ==

값이 같은지 비교한다.

```python
a = [1,2,3]
b = [1,2,3]

print(a == b)
```

결과

```python
True
```

---

### is

같은 객체를 참조하는지 비교한다.

```python
print(a is b)
```

결과

```python
False
```

---

## id()

객체의 고유한 메모리 번호를 반환한다.

```python
print(id(a))
```

같은 객체를 참조하면 id도 같다.

# 2. 가변 객체(Mutable)

## 가변 객체란?

객체 자체를 수정할 수 있는 자료형이다.

대표적인 예

- list
- dict
- set

---

### 예제

```python
a = [1,2,3]

b = a

b[0] = 100

print(a)
print(b)
```

결과

```python
[100,2,3]

[100,2,3]
```

---

### 이유

`a`와 `b`가 같은 리스트를 참조하기 때문이다.

```
a ─────┐
       ▼
   [100,2,3]
       ▲
b ─────┘
```

---

### 확인

```python
print(a is b)
```

결과

```python
True
```

---

# 3. 불변 객체(Immutable)

## 불변 객체란?

한 번 만들어지면

객체 자체를 수정할 수 없는 자료형이다.

대표적인 예

- int
- float
- str
- tuple

---

### 예제

```python
a = 20

b = a

b = 10
```

결과

```python
a = 20

b = 10
```

---

### 이유

정수는 수정되는 것이 아니라

새로운 객체를 참조하기 때문이다.

```
처음

a ───► 20
b ───►

↓

b = 10

a ───► 20

b ───► 10
```

따라서

```python
print(a is b)
```

결과

```python
False
```

---

# 4. id()로 확인하기

```python
x = [1,2,3]

y = x

z = [1,2,3]
```

```python
print(id(x))
print(id(y))
print(id(z))
```

결과

```
x와 y → 같은 id

z → 다른 id
```

---

비교

```python
print(x is y)
```

결과

```python
True
```

```python
print(x is z)
```

결과

```python
False
```

# 객체 비교 정리

|비교|의미|
|---|---|
|`==`|값이 같은가|
|`is`|같은 객체인가|
|`id()`|객체의 고유 번호 확인|

# 5. 얕은 복사(Shallow Copy)

## 왜 필요한가?

다음처럼

```python
b = a
```

를 사용하면

같은 객체를 참조하게 된다.

이를 방지하기 위해 **새로운 리스트를 만드는 것**이 얕은 복사이다.

---

## 특징

- 바깥 리스트는 새로 생성된다.
- 안쪽 객체는 그대로 공유한다.

즉,

```
a ───► [1,2,3]

b ───► [1,2,3]
```

처럼 서로 다른 리스트가 된다.

---

# 6. 얕은 복사 방법

## ① 슬라이싱

```python
a = [1,2,3]

b = a[:]
```

---

## ② copy()

가장 많이 사용하는 방법이다.

```python
a = [1,2,3]

b = a.copy()
```

---

## ③ list()

```python
a = [1,2,3]

b = list(a)
```

---

세 방법 모두

```python
print(a is b)
```

결과

```python
False
```

---

## 어떤 방법이 가장 좋은가?

|방법|추천도|
|---|---|
|`a[:]`|★★★★☆|
|`a.copy()`|★★★★★|
|`list(a)`|★★★★☆|

실무에서는 **의도가 가장 명확한 `copy()`를 많이 사용한다.**

---

# 7. 얕은 복사의 한계 ⭐

얕은 복사는

**바깥 리스트만 복사**한다.

안쪽 리스트는 그대로 공유한다.

---

예제

```python
a = [1,2,[3,4,5]]

b = a.copy()
```

현재 모습

```
a ───► [1,2, ● ]
             │
             ▼
          [3,4,5]

b ───► [1,2, ● ]
             │
             └────── 같은 객체
```

---

## 바깥 요소 수정

```python
b[0] = 999
```

결과

```python
a

[1,2,[3,4,5]]

b

[999,2,[3,4,5]]
```

영향이 없다.

---

## 안쪽 리스트 수정

```python
b[2][1] = 100
```

결과

```python
a

[1,2,[3,100,5]]

b

[999,2,[3,100,5]]
```

둘 다 변경된다.

---

### 이유

안쪽 리스트는 같은 객체를 공유하기 때문이다.

```python
print(a[2] is b[2])
```

결과

```python
True
```

---

# 얕은 복사 핵심 정리

✅ `b = a`는 복사가 아니라 **참조 공유**이다.

✅ 얕은 복사는 **바깥 리스트만 새로 생성**한다.

✅ 안쪽 리스트(중첩 리스트)는 그대로 공유한다.

✅ 중첩 리스트까지 완전히 복사하려면 **깊은 복사(Deep Copy)** 가 필요하다.

---

# 반드시 기억할 것 ⭐

|개념|의미|
|---|---|
|`=`|참조 공유|
|`==`|값 비교|
|`is`|객체 비교|
|`id()`|객체의 고유 번호|
|얕은 복사|바깥만 복사|
|깊은 복사|안쪽까지 모두 복사|
